# 00 · INDEX — 提交给网页端 AI 的读法

本包是一份**阴阳师对弈竞猜战斗模拟器**项目的可读快照，含**引擎**（battle-lab/）与**网页工作台**（apps/web/，M1.8）两部分。

工作区公开部分约 **28.3 MB / 约 8.67M token**（含知识库 JSON 与前端生成物；原始抓取与第三方克隆不进公开仓库）。远超网页端上下文。
本包把它重排成 **6 个内容文件**，按需选传 —— 单个文件都控制在 120k token 以内，任何一份都能单独贴进对话框。

## 推荐组合（都实测过，直接照抄）

| 场景 | 传这些 | 约 token | 能装下它的模型 |
|---|---|---:|---|
| **最小：只想建立认知** | 01 + 02 | **355.0k** | 几乎所有（≥32k） |
| **只想让它看懂项目** | 01 + 02 + 04 | **361.7k** | 几乎所有（≥64k） |
| **只想让它改网页前端** | 01 + 06 | **193.4k** | ≥100k |
| **只想让它改引擎** | 01 + 03 | **829.6k** | ≥100k |
| **全栈改代码** | 01 + 03 + 06 | **1019.4k** | ≥200k（贴得下但吃紧） |
| **全量** | 01 ~ 06 | **1437.8k** | 超出多数网页端，不建议一次贴 |

> **最省又信息密度最高的两个：** `01`（3.6k）+ `04`（6.7k）= **10.3k token**，不到 10k 就能建立完整认知。
> 想让它**动代码**：改前端只传 `01 + 06`（193.4k），改引擎只传 `01 + 03`（829.6k）—— 两边源码互相独立，不必一起传。
> 两边都要动时，`01 + 03 + 06` = 1019.4k token，200k 上下文刚好装得下。

## 建议的读法

1. **01-项目总览** —— 先建立全局：项目结构、三条已冻结的架构决定、里程碑（含 M1.8 网页工作台）、当前边界
2. **04-数据摘要** —— 知识库长什么样（字段、条数、样本），以及前端那几个 MB 级生成物的 schema。
   注意：**不要**要求看原始 JSON，它是本文件的 500 倍体积
3. **02-研究报告** —— 完整推导链。其中三节最关键：
   - §07 竞猜路径 vs 完整御魂系统**分层冻结**
   - §08 典型对局 #001（真实数据 + 基准夹具）
   - §04 战斗规则地基（官方术语词典 + 22 子系统）
4. **03-源码汇编**（引擎）/ **06-网页前端源码**（界面）—— 需要动代码时按需选传
5. **05-支撑材料** —— 一般不用传，只在追问「当初为什么这么定」时用

## 06 的特殊说明（传之前请读）

- `.vue` 文件**只保留 `<script>` 与 `<template>`**，`<style>` 段（约 32 KB 纯样式）已整段剔除，剔除处留一行 HTML 注释标记。
  这是为了让 06 控制在 189.7k token；组件逻辑一字未改。
- 生成物（`src/engine/bundle.json` 621 KB、`src/kb/*.json` 730 KB、`package-lock.json`）**不在 06 里**，它们的 schema 与体积在 04。
- 因此 06 里的代码是「可读、可改」的，但**不是**一个能原样复制回项目就构建的完整目录（缺样式与生成物）。

## 如果你只想知道「这东西现在能干什么」

看 **01-项目总览** 的最后一节「当前边界」：

> 模拟器能跑完整对局，但**产出的胜率目前不可用于下注** ——
> 四个未实测的机制参数（开局结算顺序 / 同时触发优先级 / 死亡转化复活状态机 / 竞猜残局规则）
> 全部做成了可切换策略并强制带 UNKNOWN 警示，不允许靠猜测补值。

M1.8 网页工作台（06）没有改变这一点：它只是把同一套引擎与知识库搬进浏览器；M1.9 之后这一条多了三件**可跑的仪器**（都在 battle-lab/tools/）：`fidelity-cli.ts report|diff`（五层保真度 + 与真实观测对照找第一处分歧）· `replay-cli.ts run --out f` + `verify f`（逐帧回放校验）· `state-cli.ts save|resume`（暂停存档 → 换进程续跑）。十二项目标各自的守门人与最近实跑结果见 02 的 **§172**。
结果面板顶部会挂 UNKNOWN 警示，机制实验台直接列出每个红区的状态与 44 个可判别实验。

## 未包含

- **前端生成物**（apps/web/src/engine/bundle.json 621 KB + apps/web/src/kb/*.json 730 KB = 约 1.4 MB）
  —— 只在 **04** 里描述 schema、条数与重建命令
- **原始抓取产物与第三方克隆**（`data/raw/`、`_oas/`、`_nga/`、`reference/`）——不进公开 Git 仓库，也不收录进本包
- **二进制文档**（`.docx`）—— 网页端 AI 读不了，其内容已大量引用于报告 02
- **可运行副本** —— 本项目需要 Node ≥22 原生 TS 类型擦除，网页端 AI 无法执行；
  所有测试的**实测结果**已写进 01 与 02
